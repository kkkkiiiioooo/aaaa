# Experiment E0.1 — Base image provenance

## Objective

Determine which provided WIM can serve as the driver base and record the provenance evidence for the 1809 and 10586 images.

## Fidelity level

`metadata only`. This experiment does not boot Windows, load a driver, or test hardware. It records WIM metadata, DriverStore contents, and file hashes.

## Preconditions

- The tracked WIM parts are present under `winre-1809-254MB/` and `winre-fabrica-10586-424MB/`.
- `wimlib-imagex`, `sha256sum`, and `stat` are available.
- The target DriverStore state is present under `drivers/estado-dispositivo/`.
- No tracked WIM part is modified. Reassembly is done on copies under `/tmp`.

## Environment

- Date: 2026-11-13
- Host: Linux container, Ubuntu 24.04
- Kernel: `6.8.0-1070-azure`
- Virtualization: KVM device present; no VM booted in this experiment
- CPU: 2 vCPU
- Memory: 7.8 GiB total
- Tool: `wimlib-imagex 1.14.4-1.1build2`
- Reassembled images:
  - `/tmp/opencode/winre/winre-1809.wim`
  - `/tmp/opencode/winre/winre-fabrica-10586.wim`

## Commands

```sh
mkdir -p /tmp/opencode/winre
cat winre-1809-254MB/winre-1809.wim.part-* \
  > /tmp/opencode/winre/winre-1809.wim
cat winre-fabrica-10586-424MB/winre-fabrica-10586.wim.part-* \
  > /tmp/opencode/winre/winre-fabrica-10586.wim

sha256sum /tmp/opencode/winre/winre-1809.wim \
          /tmp/opencode/winre/winre-fabrica-10586.wim

wimlib-imagex info /tmp/opencode/winre/winre-1809.wim
wimlib-imagex info /tmp/opencode/winre/winre-fabrica-10586.wim

wimlib-imagex dir /tmp/opencode/winre/winre-1809.wim 1 \
  --path='Windows/System32/DriverStore/FileRepository' \
  | grep -i 'bcm\|broadcom' | sort

wimlib-imagex dir /tmp/opencode/winre/winre-fabrica-10586.wim 1 \
  --path='Windows/System32/DriverStore/FileRepository' \
  | grep -i 'bcm\|broadcom' | sort

sha256sum /tmp/opencode/wim-extract/* \
  drivers/estado-dispositivo/bcmwdidhdpcie.inf_amd64_977dcc915465b0e9/*
```

## Interpretation

### Observed facts

- Only the 1809 WIM contains `bcmwdidhdpcie.inf` version `1.558.53.25`.
- The 10586 WIM contains bcmdhd, bcmdhd64, bcmfn2, and bcmfn, but no `bcmwdidhdpcie.inf`.
- The target state under `drivers/estado-dispositivo/` matches the 1809 extraction byte for byte.
- The 1809 WIM is build 17763.1; the factory WIM is build 10586.
- The 1809 driver folder is four files and has no nvram.

### Hypotheses

- The 1809 WIM is a Microsoft WinRE 1809 image. Its build, edition, architecture, and timestamps are consistent with that, but there is no official reference hash to prove it.
- The 10586 WIM is the factory recovery extracted from the device `System Recovery` partition. This comes from the user's report, not an independent source.
- The real 398 MB partition is a 1809 recovery image with OEM extras. The 1809 WIM plus OEM extras from the 10586 WIM is the closest available approximation.
- The 2017 PCIe package was not injected by a later step. This is not proven; the metadata is consistent with an official image, but the repository cannot rule out injection without a reference image.

## Decision

- Result: blocked. The evidence is recorded, but the provenance of the 1809 WIM is not independently verified.
- No base is approved yet.
- Candidate: F2 (1809 + OEM extras from 10586), only if the 1809 WIM is verified against an official reference.
- Fallback: F1 (1809 only) for driver mechanics, also subject to the same provenance check.
- The 10586 WIM is not a driver base. A 10586-plus-injected-2017-driver variant (F2b) is less faithful and is only a control.
- Next experiment: obtain an official 1809 reference, verify its hash, and compare the WinRE contents before selecting a base.

## Limitations

- No official reference hash for the 1809 WIM is available, so provenance is not independently verified.
- The 398 MB device image is unavailable and cannot be transferred from the device.
- QEMU does not emulate the BCM4356, so no radio or error-10 conclusion follows from the image metadata.
- File hashes prove content equality, not origin.

## Rollback

- No tracked WIM was modified. Reassembly and extraction were done under `/tmp/opencode/`.
- To remove the temporary copies, delete `/tmp/opencode/winre/` and `/tmp/opencode/wim-extract/`.
- Repository files were not changed by this experiment.
