# Projeto wwii

Recuperação do Windows sem conexões físicas (WinRE 1809).

**Comece por `AGENTS.md`**: ele traz os comandos de início e indica o resto. Demais arquivos só sob demanda.
Entrada: `sh iniciar.sh A=<nome> M=<modelo-exato> P=wwii S_ARQ=<arquivo-da-passphrase>`. Sem prompt: `sh auto.sh`.
Consulta: `docs/imagem/INVENTARIO.md` (o que existe no WinRE) · `EVALS.md` · `scripts/README.md` · `ETAPAS.md`.
Branches: `wwii` (trabalho) · `lider` · `info` · `imagem`. Nunca `main`, `0`, `backup`.
Avanço real: `sh scripts/evals.sh`. Regra: trabalhe até se esgotar (AGENTS.md).
