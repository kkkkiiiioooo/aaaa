# Projeto (template)

Ramo criado a partir do template: `TASK.md` (problema), `events/` (estado), `HANDOFF/` (recados).

    sh iniciar.sh A=<nome> P=<projeto>        # ou: sh h.sh
    sh bin/reivindicar.sh <ID>
    sh bin/liberar.sh <ID> feita "<caminho: saida>"

`BOARD.md` e `PROGRESS.md` sao gerados por `bin/board.sh`; nao edite.
